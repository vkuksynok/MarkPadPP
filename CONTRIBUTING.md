# Contributing to MarkPad++

Thank you for helping improve MarkPad++. This repository is where bug reports,
feature requests and documentation fixes are handled.

## MarkPad++ is closed source

The application's source code is **not public** and is not hosted here. This
repository holds only the documentation and the issue tracker.

**Pull requests containing application source code cannot be accepted**, because
the code lives in a private repository. Please do not open PRs that add or modify
application code.

## What is welcome

- **Bug reports.** Open a [bug report](https://github.com/vkuksynok/MarkPadPP/issues/new?template=bug_report.yml)
  and include your MarkPad++ version, Windows version, the steps to reproduce, and
  what you expected versus what happened. A small sample `.md` file that triggers
  the problem helps a lot.
- **Feature requests.** Open a [feature request](https://github.com/vkuksynok/MarkPadPP/issues/new?template=feature_request.yml)
  describing the problem you are trying to solve, not only the solution you have in
  mind.
- **Documentation fixes.** Corrections and improvements to the files in this
  repository (`README.md`, `docs/`, `CHANGELOG.md`) are welcome as pull requests.

## Before you open an issue

- Check the [existing issues](https://github.com/vkuksynok/MarkPadPP/issues) to
  avoid duplicates.
- Confirm you are on the latest version — updates arrive through the Microsoft
  Store.
- Read the [documentation](docs/index.md); some behaviour that looks like a bug is
  a documented limit (for example, there is no live side-by-side preview, and
  search is literal rather than regex).

## Reporting a security issue

Please do not report security vulnerabilities in public issues. See
[SECURITY.md](SECURITY.md) for how to report them privately.
